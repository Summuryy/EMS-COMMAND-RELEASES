# EMS COMMAND — официальный канал бинарных обновлений

Здесь публикуются **только собранные Windows-файлы** EMS COMMAND. Исходный код, пользовательские данные, пароли, токены и закрытые ключи подписи сюда не загружаются.

## Новый формат: portable-лаунчер

Разрабатывается в отдельном Pull Request №2 приватного проекта. После официального выпуска GitHub Release содержит:

- `EMS-COMMAND-Launcher-<version>-win-x64.exe` — независимый portable-лаунчер Windows (не мастер установки NSIS)
- `EMS-COMMAND-App-<version>-win-x64.zip` — готовая сборка приложения Electron
- `ems-manifest.json` — Ed25519-подписанный манифест, содержащий SHA-256 архива и каждого файла

Лаунчер проверяет подпись по закреплённому публичному ключу, затем проверяет хеши, распаковывает версию в каталог пользователя и запускает EMS COMMAND. Система предусматривает восстановление повреждённых файлов и откат на предыдущую проверенную версию.

**Важно:** подпись Ed25519 не является Windows Authenticode; неподписанный Windows EXE может вызывать предупреждения SmartScreen. Приватный ключ не должен попадать в релизы.

## Текущий статус

Публичный репозиторий существует. Первой **продукционной** публикации нового формата должен предшествовать выпуск стабильного постоянного Ed25519-ключа и настройка защищённой GitHub Actions environment `production`. Черновые QA-сборки с временным ключом **не являются** публичными релизами.

GitHub Actions публикации исходного проекта требует: `EMS_MANIFEST_SIGNING_KEY_PEM_B64` (секрет production), `EMS_LAUNCHER_PUBLIC_KEY_PEM_B64` (переменная production), `EMS_RELEASES_TOKEN` (секрет production, минимальные права на этот репозиторий). Действия по генерации ключей выполняются только на устройстве владельца.

## Старый формат

Ранее использовались NSIS / `latest.yml` / `.blockmap`. Старый канал может оставаться совместимым с ранее выпущенными сборками, но для новой portable-схемы используется **отдельный** подписанный JSON-манифест. Не смешивайте форматы или QA-артефакты с продукционными релизами.

Проверяйте публикации по тегу версии и источнику скачивания; не запускать произвольные EXE из чужих ссылок.
