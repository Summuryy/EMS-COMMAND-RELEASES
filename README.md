# EMS COMMAND — публичный канал обновлений

Это **официальный канал доставки Windows-релизов** EMS COMMAND. Репозиторий публичный только для скачивания сборок. Исходный код приложения хранится отдельно, в приватном `Summuryy/EMS-COMMAND`.

## Как будут появляться обновления

1. Разработчик проверяет исходники и тесты в приватном репозитории.
2. GitHub Actions собирает и подписывает установщик Windows.
3. В этом репозитории создаётся GitHub Release с `latest.yml`, `.exe` и `.blockmap`.
4. Установленный лаунчер проверяет публичный HTTPS-канал и загружает новую версию.
5. Пользователь подтверждает установку после завершения смены.

**Статус на 9 ноября 2026:** канал создан, но опубликованных подписанных версий пока нет. Автообновление не запущено.

## Важно

- Никогда не загружать сюда базу данных, скриншоты игроков, пароли, токены или сертификаты подписи.
- Не выпускать неподписанные экспериментальные EXE как стабильное обновление.
- Не публиковать исходники приложения.
- Не использовать пользовательские файлы или артефакты тестовых GitHub Actions вместо подготовленных релизов.

## Где настроить публикацию

Настройки находятся в **приватном** исходном репозитории: `Settings → Secrets and variables → Actions`.
Нужны переменные `EMS_RELEASE_REPO` и `EMS_UPDATE_FEED_URL`, а также секреты `EMS_RELEASES_TOKEN`, `CSC_LINK` и `CSC_KEY_PASSWORD`.

Подробности: `Summuryy/EMS-COMMAND/docs/UPDATE_ARCHITECTURE_RU.md`.
